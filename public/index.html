A Few Lines About Me

As a fourth-year Computer Applications student specializing in Embedded Systems, my perspective shifted somewhere between my first blinking LED and my first real-time temperature sensor: microcontrollers stopped being passive circuitry and became quiet, patient collaborators.

I specialize in low-level systems engineering: developing C++ firmware, architecting deterministic RTOS environments, and integrating sensors for real-time physical telemetry. Working within hard constraints demands total discipline—where performance is measured cycle by cycle, debugging means observing physical behavior, and software must fit strictly within hardware allocations.

My goal in embedded engineering is to build quiet, context-aware systems. Designing hardware capable of detecting and responding to physical shifts faster than human perception represents the true purpose of my work.

Achievements

Participation — RT-Thread Based Technologies

Selected to participate in the RT-Thread Based Technologies introduction to open-source real-time systems — a program focused on the RT-Thread open-source RTOS and its growing ecosystem in the embedded world.

Presentation — Space Dodger: High-Performance LVGL Game on HMI-Board Game on RT-Thread

Showcased Space Dodger, an embedded HMI game built to demonstrate RT-Thread's real-time UI rendering , event handling, and state management capabilities on a single board. Presenting this system on an industry stage transformed my perspective, marking the transition from academic study to professional systems engineering

From blinking an LED to presenting an HMI game built on a real open-source RTOS — that, in one sentence, has been the arc of the last four years.
